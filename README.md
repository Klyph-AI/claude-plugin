# Klyph Claude Code plugin

Klyph turns long videos into short clips. This plugin connects Claude Code to your Klyph account so you can import or upload a video, pick clips, change captions, render, and download, all from the terminal.

Klyph clips and edits your own videos. It is not AI video generation.

## Install

```
/plugin marketplace add Klyph-AI/claude-plugin
/plugin install klyph@klyph
```

Run `/mcp`, choose `klyph`, and sign in. Full details are in [plugins/klyph/README.md](plugins/klyph/README.md).
